QWidget类

Qt中常见的界面组件





QWidget

  • QWidget是所有界面组件类的基类，其定义的一些属性、接口函数、信号与槽是所有界面组件共有的
  • 当QWidget作为界面组件时的属性（通常情况下，一个属性会有一个读取函数与一个设置函数，如属性font：font()与setFont()）

    • QSizePolicy还有水平延展与垂直延展，即当前组件在布局中所占的宽度与高度，通常为0（均分），例如：三个按钮的水平延展因子为1、1、2，相当于把总宽度分为四等份，第三个按钮是第一个或第二个的2倍

QMainWindow与QAction

  • QMainWindow是主窗口类，具有菜单栏、工具栏、状态栏等界面元素，要设计它们需要用到QAction类（实现某个功能的“动作”，其父类是QObject）
  • 在Qt Designer界面中有一个Action编辑器，用于可视化设计Action如下图：
  • 编辑或新建一个Action，包括以下一些设置内容：
    • Object name，Action对象名称，应遵循自身的命名规则，如使用act...开头
    • ToolTip，鼠标悬停按钮上方显示的提示文字
  • Action具有下列属性：
    • statusTip，鼠标悬停到该按钮时，主窗口下方状态栏的临时消息区显示的文字
    • shortcutContext，Action快捷键的有效响应范围，默认为WindowShortcut（只有是当前窗口的子组件时快捷键有效，如果值为ApplicationShortcut，表示只要是应用程序有窗口显示，则有效）

菜单栏、工具栏与状态栏

  • 分别对应类QMenuBar QToolBar QStatusBar，均继承自QWidget
  • 一个主窗口上最多有一个菜单栏和一个状态栏，可以有多个工具栏
    • 窗体最上方是菜单栏，菜单栏下方是工具栏，最下方是状态栏

布局管理

容器组件

  • 任何布局类对象在可视化设计时都有layoutLeftMargin、layoutTopMargin、layoutRightMargin和layoutBottomMargin这 4 个边距属性决定与父组件的边距（最小值）
  • LayoutSpacing属性（垂直与水平布局，网格布局类似，但其为layoutHorizontalSpacing等）决定组件间的距离（最小值）
  • 均使用addWidget函数添加组件（网格布局函数声明略有不同：void QGridLayout::addWidget(QWidget *widget, int fromRow, int fromColumn, int rowSpan,int columnSpan, Qt::Alignment alignment = Qt::Alignment())，其需要传入所在行列号及其占用行列数）

分割条

  • QSplitter，可实现水平或垂直分割，通常是在两个可以自由改变大小的组件进行分割

QString

  • QString的每个字符均为QChar类型数据（QChar使用UTF-16编码，而大多IDE源文件默认使用UTF-8保存，但QString构造函数内部默认会调用静态函数fromUtf8进行转换）
  • QString支持使用+（或append，preappend在当前字符串前添加）进行字符串拼接
  • front/back获取字符串首或尾的字符
  • left/right从字符串中提前左边或右边n个字符，Qt6引入的first/last与其功能相同，但执行速度更快
  • isNull与isEmpty，前者只有未赋值时才返回true（空字符串\0，前者返回false，后者返回true）
  • count size length clear resize fill见IDE具体函数声明
  • indexOf与lastIndexOf，前者查找某个字符串首次出现的位置，后者则是最后出现的位置
  • contains包含指定字符
  • endsWith与startsWith
  • toUpper toLower trimmed simplified，simplified除了去除首尾空格，还会将中间连续的空格用当个空格替换
  • chop去掉字符串末尾的n个字符（若n大于实际字符串长度，则内容变为空）
  • insert replace remove
  • toX进行转换，X可替换为Int UInt Long ULong Short... Float Double，通常其参数为bool* ok=nullptr，其保存转换是否成功，针对整数类型有第二个参数int base=10
  • setNum将整数或浮点数转化成字符串，静态函数QString::number与其功能相同

  • 静态函数QString::asprintf与printf类似
  • 函数arg

QChar

  • QChar定义了很多接口函数用于字符串操作

Latin1字符集是对ASCII字符集的拓展，1字节编码，用128~255表示拉丁字母中特殊语言字符的编码

QSpinBox与QDoubleSpinBox

  • 两者均为常用的数值输入与输出组件，统称为SpinBox，前者用于整数，后者用于浮点数
  • 均继承自QAbstractSpinBox
  • 与QWidget一样，每个属性都有setter与getter

按钮组件

  • QPushButton具有属性：autoDefault（获得焦点时的默认按钮） default flat，其中flat指：为true时，按钮没有边框，仅在被点击或复选时才显示边框（QPushButton的checkable属性默认是false，可复选通常代表当前按钮会保持当前的状态）
  • QCheckBox具有属性tristate，即三种复选状态：Checked Unchecked PartiallyChecked，且定义了checkState setCheckState读取与设置复选状态（QAbstractButton的isChecked与setChecked也可以使用）

QSlider与QProgressBar

  • QSlider（滑动条），QScrollBar（卷滚条）与QDial（表盘）均继承自QAbstractSlider，QProgressBar是进度条
  • QAbstractSlider
  • QSlider具有属性tickPosition与tickInterval，即标尺刻度的显示位置与间隔值
  • QScrollBar通常与文本编辑器或容器组件组合使用
  • QDial具有属性notchesVisivle、notchTarger与wrapping，即表盘外围小刻度线是否可见、刻度间的间隔像素值与首位刻度是否连贯
  • QProgressBar继承于QWidget，具有属性：textDirection于format（默认为%p%显示百分比，%v显示当前值，%m显示总步数）

日期时间

  • QTime QDate QDateTime为存储日期时间数据的类，对应的组件为QTimeEdit QDateEdit QDateTimeEdit QCalendarWidget（日历显示）

数据类

  • QTime
  • QDate
  • QDateTime
  • QTime QDate QDateTime都有函数toString与静态函数fromString
  • 日期时间常用格式

界面组件

  • QDateTimeEdit及其子类QTimeEdit、QDateEdit，其中QDateTimeEdit的父类为QAbstractSpinBox，因此其与QSpinBox有些类似
  • QDateTimeEdit定义了以下属性：currentSection（当前光标所在[时/分/秒]输入段）、currentSectionIndex、calendarPopup（是否允许弹出一个日历选择框）与displayFormat（日期时间显示格式，如表4-16所示）
  • QCalendarWidget

QTimer与QElapsedTimer

  • QTimer是软件定时器，其父类为QObject，设置以毫秒为单位的定时周期，然后继续连续定时或单次定时，若定时溢出会发射timeout()信号
  • QElapsedTimer用于快速计算两个事件的间隔时间，是软件计时器，其没有父类，定时精度可以到达纳秒级

QComboBox

  • 下拉列表框组件，提供下拉列表供用户选择输入，也可以提供编辑框用于输入文字
  • 下拉列表的每个项可以存储一个或多个QVariant类型用户数据

处理项数据的组件

  • Qt中有两类：一类是Item Views组件，包括QListView QTreeView QTableView，另一类是Item Widgets组件，包括QListWidget QTreeWidget QTableWidget，下文介绍界面组件类

QToolButton与QListWidget

  • QToolButton有一个setDefaultAction函数，使按钮与Action关联，此时，点击一个工具按钮与点击工具栏的按钮一样会运行Action的triggered信号关联的槽函数

  • QToolBox是工具箱组件类，是一种垂直分页的多页容器组件，如上图左半部分所示，工具箱的每个页面就是一个QWidget组件
  • QListWidget组件如上图右半部分所示，每一行是一个QListWidgetItem类型对象（称之为项或列表项），每个列表项有自己的属性，包括文字、字体、对齐方式、背景色、前景色等
    • 因此通常在列表中添加或插入一个项，则是先创建一个QListWidgetItem对象，设置特性，再使用函数addItem insertItem将其加入列表
    • 使用setFlags设置一些特性，函数原型为void QListWidgetItem::setFlags(Qt::ItemFlags flags)


  • QListWidget的信号
    • 在 QListWidget 组件上点击某个项而导致当前项发生切换时，组件会发射 4 个信号，表示当前项发生了变化，这 4 个信号是 currentItemChanged()、currentRowChanged()、currentTextChanged()和 itemSelectionChanged()
    • 点击一个项时，不管是否发生了当前项的切换，都会发射 itemPressed()和 itemClicked()信号
