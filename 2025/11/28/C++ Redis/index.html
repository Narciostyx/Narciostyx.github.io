C++ Redis开发

RESP

  • Redis序列化协议，即redis客户端与redis服务器相互通信时使用的协议
  • 协议使用CRLF\r\n作为终止分隔符
  • 采用前缀长度传输数据块，确保二进制数据的安全传输
  • 请求报文格式
  • 响应报文格式（其第一个字节始终标识其类型）

其他数据类型请参阅

RedisPlusPlus

项目地址

  • 该库是基于C语言客户端hiredis的封装（依赖于hiredis）
  • 连接池的连接是延迟创建的
  • 共享Redis类在多线程环境下调用成员函数是安全的，因此尽可能重用Redis对象
  • 即使Redis连接服务器失败或某个时刻断开，当发生命令是会抛出异常Error，但Redis会自动重连，成功则发送命令并执行，反之继续抛出异常（因此可以重用Redis对象）
  • 支持TLS连接
  • API文档
  • 示例
  • 实际开发考虑ConnectionPoolOptions连接池选项达到支持高并发，管道批量操作等
