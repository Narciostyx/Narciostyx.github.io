IP协议

IP网络层协议、IPv4报文格式与分片

  • IP协议向上层提供**无状态（不同步传输数据的状态信息）、无连接、不可靠（不保证数据报准确到达接收端，只是承诺尽最大努力）**的服务
  • IPv4报文头部，通常为20字节，最长为60字节
    • TOS包含一个3位的优先权字段（现已被忽略），4位TOS字段与1位保留字段（必须置零），其中4位TOS字段分为：最小延时，最大吞吐量，最高可靠性与最小费用（有且仅能有一个置1）
    • 标识用于唯一标识主机发送的每一个数据报文，初始值由系统随机生成
    • 标志的第一位保留，第二位代表DF（Don’t Fragment，禁止分片，但当当前IP数据报长度超过MTU，则之间丢弃并返回ICMP差错报文），第三位代表MF（More Fragment，更多分片，除了数据报的最后一个分片外（代表当前为最后一个分片），其余分片需要均置为1）
    • 片偏移为当前分片相对原始数据（实际数据）报开始处，其值为该值左移三位得到的，因此每个分片数据长度必须是8的整倍数
    • TTL通常为64
    • 选项字段最多包含40字节，如记录路由（将经过的所有路由器IP填入IP头部的选项部分）、时间戳（将所有路由转发数据报的时间填入）、松散源路由选择（指定一个路由器IP地址列表，数据报发送过程种必须经过所有其中的路由器）、严格源路由选择（即不经过路由器IP列表的所有路由器）

IP(v4)分片

  • 分片可能发生在发送端、中转路由等（取决于其设置的MTU大小），甚至多次分片，只有在最终的目标机器上，才会被重新组装
  • IP数据报数据部分最大为1480字节（以太网帧的最大数据长度1500字节减去IP数据报最小头部20字节）
  • 分片与重组依赖于数据报标识（具有相同的标识值）、标志与片偏移
  • 每个分片除总长度、片偏移、标志不同，其余一致，总长度为当前分片大小、片偏移为当前分片在原始数据部分的偏移左移三位、被分片的非最后一个分片的标志位MF应置1

IP路由

  • IP协议的核心任务即转发数据报
  • 相关的路由算法在此不进行赘述
  • 路由表可以使用route或netstat查看，下介绍route命令的部分字段属性与选项
    • Flags，U（该路由项是活动的）、H（该路由项的目标是一台主机）、G（该路由项的目标是网关）、D（该路由项是由重定向生成的）、M（该路由项被重定向修改过）
    • metric，路由距离，即到达指定网络所需要的跳数
    • ref，linux未使用，路由项被引用的次数
    • use，该路由项被引用的次数
    • add增添路由表内容，如route add -host 192.168.1.100 dev eth0，即发送到192.168.1.100主机的内容均通过网卡eth0发送，若为route add default gw 192.168.1.100 dev eth0即将默认路由选项网关设置到192.168.1.100并通过eth0网卡转发（dev代表网卡选项）
    • del删除路由表内容，如route del -net 192.168.1.0 netmask 255.255.255.0，即删除网络192.168.1.0/24对应的路由项，若为route del default即删除默认路由选项

IP转发

  • 主机可以设置数据转发功能，该功能由/proc/sys/net/ipv4/ip_forward决定，内核参数默认为0，可设置为1启动转发功能

重定向

  • ICMP重定向报文可以用于更新路由表
  • /proc/sys/net/ipv4/conf/all/send_redirects决定是否允许发送ICMP重定向报文
  • /proc/sys/net/ipv4/conf/all/accept_redirects决定是否允许接收ICMP重定向报文
  • 通常主机只能接收ICMP重定向报文，路由器只能发送ICMP重定向报文

IPv6协议

  • IPv6报文固定头部如下图：
    • 通信类型与IPv4的TOS类似
    • 流标签是IPv6新增的字段，用于某些对连接的服务质量有特殊要求的通信，如音频视频等实时数据传输
    • 净荷长度即IPv6拓展头部与应用程序数据长度之和，不包含固定头长
    • 下一个包头，即IPv6固定头部紧跟的包头类型，如拓展头、上层协议头
    • 零压缩，即省略连续的、全零的组，如：FE80:0000:0000:0000:1234:5678:0000:0012，可以写成FE80::1234:5678:0000:0012，但零压缩只能省略一次（否则无法计算具体省略了多少个全零组）
  • IPv6拓展头部，如下图：
    • 拓展头部可以为0，代表没有任何拓展头部
    • 应该数据报可包含多个拓展头部，每个头部的类型由前一个头部的下一个包头字段指定
  • IPv6并非IPv4的简单拓展，其两者为完全独立的协议
